## State before the step

There is no `lib/metrics/` folder. The dashboard and the charts have no source for
their numbers.

## Goal

Four pure functions produce every derived number in Phase 1. None of them throws.

## Do

Write these four files, tests first.

| File                | Function                                                   |
| ------------------- | ---------------------------------------------------------- |
| `streak.ts`         | The current streak and the longest streak from a date list |
| `movingAverage.ts`  | A 7-day average over sparse dates                          |
| `weekTotals.ts`     | Sessions, gym seconds, walk seconds, calories, steps       |
| `heartRateZones.ts` | Split a session into warm, fat burn, cardio and peak       |

All four are pure. None of them reads the database. The caller passes the rows in.

## Acceptance criteria

**`streak`**

- [ ] No entries returns 0 and 0.
- [ ] One entry today returns a current streak of 1.
- [ ] One entry yesterday and none today returns a current streak of 1.
- [ ] A gap of one day breaks the current streak.
- [ ] A gap of three days breaks the current streak.
- [ ] Two entries on the same date count as one day.
- [ ] A run that crosses a month boundary stays unbroken.
- [ ] An entry at 23:30 local time counts for that local day, not the next UTC day.

**`movingAverage`**

- [ ] A window shorter than 7 days returns a value, not null.
- [ ] Sparse dates do not shift the window.
- [ ] The result at index 0 equals the first value.

**`weekTotals`**

- [ ] An empty week returns zeros, not null.
- [ ] A week with a null weight does not produce `NaN`.
- [ ] A week that crosses a month boundary totals correctly.

**`heartRateZones`**

- [ ] The four zone shares add up to the session length.
- [ ] A session with no heart rate returns four zeros.

**All four**

- [ ] Every function returns a safe value for an empty input. None of them throws.
- [ ] Coverage on `lib/metrics/**` is 100 percent for lines and functions, and 95
      percent or better for branches.
