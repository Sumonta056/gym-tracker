# Step 1.2 — Generated types and the Supabase clients

**Branch:** `feat/phase-1-daily-tracker` · **Size:** S · **Depends on:** 1.1
**Unlocks:** 1.3, 1.7

## Context to read first

1. `.claude/rules/architecture.md`, rule 1, the repository rule.
2. `eslint.config.mjs` — find the existing `no-restricted-imports` block.
3. `S1.1-supabase-migration.md` — the migration this step reads types from.

## State before the step

Migration 0001 is applied. `@supabase/supabase-js` and `@supabase/ssr` are not
installed. No ESLint rule blocks a Supabase import yet.

## Goal

Three Supabase clients exist. Generated types match the database. ESLint blocks any
screen that imports them.

## Do

1. Install `@supabase/supabase-js` and `@supabase/ssr`.
2. Generate the types:
   `pnpm supabase gen types typescript --project-id <id> > lib/supabase/database.types.ts`
3. Add the script `"types:db"` to `package.json` so the command is repeatable.
4. Write three clients:
   - `lib/supabase/client.ts` — the browser client.
   - `lib/supabase/server.ts` — server components and route handlers.
   - `lib/supabase/middleware.ts` — session refresh.
5. Extend `no-restricted-imports` in `eslint.config.mjs`. For files under `app/**`
   and `components/**`, block `@supabase/*`, `lib/supabase/*` and `lib/sync/*`.
   Give the rule a message that names the repository rule.
6. Add the three new files to the `EXEMPT` list in `scripts/require-tests.mjs` only
   if they hold no logic. Prefer a real test. Give a reason for each exemption.

## Acceptance criteria

- [ ] `lib/supabase/database.types.ts` holds a `daily_entries` row type with every
      column from 1.1.
- [ ] `pnpm types:db` regenerates the file with no diff.
- [ ] Each of the three clients builds with TypeScript strict on.
- [ ] `pnpm lint` fails when a file under `app/` imports `lib/supabase/client.ts`.
- [ ] `pnpm lint` passes once that import is removed.

## Verification

1. Add a deliberate bad import in `app/page.tsx`. Run `pnpm lint`. Record the error
   text in the commit report. Remove the import.
2. `pnpm verify` is green.
