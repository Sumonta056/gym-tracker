# Step 2.9c — Apply the import: Skip, Overwrite or Merge

**Branch:** `feat/phase-2-workout-log` · **Size:** M · **Depends on:** 2.9b
**Unlocks:** Checkpoint C · **Agent to use:** `sync-auditor` before the step ends

The import is a normal write. It goes through the repository, so it syncs like any
other day.

## Context to read first

1. `.claude/rules/architecture.md`, rules 1 to 3.
2. `lib/db/repository.ts` — `upsertDay` and the duplicate date rule in the worker.
3. `components/csv/ImportReview.tsx` from step 2.9b.

## State before the step

The review screen resolves every cell. Apply does nothing yet.

## Goal

After one confirm, the 16 old rows are in the app and queued to sync, with the
user's choice for each date that already has a row.

## Do

1. A row whose date already has a daily entry shows 3 choices: Skip, Overwrite or
   Merge. Merge fills only the fields that are null in the existing row.
2. A confirm sheet states the counts: new, overwritten, merged, skipped.
3. Add `importDays(rows)` to the repository. It writes every row and its outbox entry
   in one transaction, and checks `signed_out`.
4. After Apply, go to `/` and show the result as text.

## Acceptance criteria

- [ ] Applying the sheet to an empty device creates 16 entries and 16 outbox entries.
- [ ] Skip leaves the existing row and writes no outbox entry for it.
- [ ] Overwrite replaces the fields and keeps the existing `id`.
- [ ] Merge fills only the null fields.
- [ ] A failure half way writes nothing. The transaction rolls back.
- [ ] Nothing is written before the user confirms.

## Tests

- Integration: the first 5 criteria, against the repository with `fake-indexeddb`.
- E2E: import the real file, review it, apply it, and the charts fill in.

## Verification

1. The `sync-auditor` agent confirms one outbox entry for each written row.
2. By hand: apply online. The 16 rows appear in Supabase.
3. `pnpm verify`.

## Risk

Overwrite must keep the local `id`. A new id for an existing date hits the unique
date index on the server and takes the duplicate date path. Test it.
