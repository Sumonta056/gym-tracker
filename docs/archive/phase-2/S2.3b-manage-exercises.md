## State before the step

The user can create an exercise. The user cannot rename, archive or restore one.

## Goal

The user keeps the exercise list clean without losing any past set.

## Do

1. Add a "Manage exercises" row to `/profile`. It opens a `SheetModal`.
2. The sheet lists the user's own exercises, active first, then archived.
3. Each own exercise has Rename and Archive. An archived one has Restore.
4. A global exercise shows no action. It shows the label "Built in".
5. Archive never deletes a set. Past sessions still show the exercise name.

## Acceptance criteria

- [ ] Rename changes the name in the picker at once.
- [ ] Archive hides the exercise from the picker. Restore shows it again.
- [ ] A global exercise has no Rename or Archive button.
- [ ] A past set of an archived exercise still shows its name.
- [ ] Every button has an accessible name that includes the exercise name.
