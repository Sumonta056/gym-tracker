# Step 2.10 — The CSV export and the round trip

**Branch:** `feat/phase-2-workout-log` · **Size:** S · **Depends on:** 2.9a
**Unlocks:** 2.11

The user owns the data. The export works in the gym, with no network.

## Context to read first

1. `lib/csv/import.ts` from step 2.9a.
2. `lib/duration.ts` — `formatDuration(seconds, 'clock')`.
3. `components/profile/DataCard.tsx`.

## State before the step

Data comes in through the import. Nothing takes it out.

## Goal

One tap saves every table as CSV, in one zip file, read from Dexie.

## Do

1. Ask the owner to approve `fflate` as a new dependency. Install it only after a yes.
2. Write `lib/csv/export.ts`. It writes one CSV for each table: daily entries,
   exercises, sessions and sets. It hides soft-deleted rows.
3. Durations export in `h:mm:ss`, so the daily entries file round trips through the
   importer.
4. The Data card gains "Export all data". It reads from Dexie only and saves
   `gym-tracker-<date>.zip`.

## Acceptance criteria

- [ ] Export then import of the daily entries returns the same data. A test asserts
      the full round trip.
- [ ] Every duration in the file parses back with `certain: true`.
- [ ] The export runs with the network down.
- [ ] A soft-deleted row is not in the file.

## Tests

- Unit: the round trip, and the soft-deleted row.
- Component: the button calls the export and starts a download.

## Verification

1. By hand: export offline and open the zip.
2. `pnpm verify`.
