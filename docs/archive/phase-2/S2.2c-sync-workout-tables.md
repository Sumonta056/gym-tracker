the gym. Write every test before the implementation.

## State before the step

The repository queues writes for 3 new tables. The worker knows only `profiles` and
`daily_entries`, so those entries never drain.

## Goal

A session, its sets and a custom exercise sync both ways, with no lost write, no
duplicate row, and no push of a global seed row.

## Do

1. Add a push mapping and a pull mapping for `exercises`, `workout_sessions` and
   `workout_sets`.
2. **Owner column.** On push, fill `user_id` from the session on `exercises` and
   `workout_sessions`. `workout_sets` has no owner column.
3. **Global rows.** Pull reads rows with `user_id is null` too, and keeps the null.
   Push never sends a row with a null owner. The repository already refuses the
   write, so the worker treats such an entry as a permanent error.
4. **Parent first.** A set never pushes before its session, and a set never pushes
   before a custom exercise it points to. The outbox sequence already gives this
   order. Add a test that proves it. A foreign key refusal is a transient error, not
   a dead letter.
5. **One active session.** A push refused by the partial unique index (`23505` on
   `workout_sessions`) is a named case. Move it to `deadLetters` with a clear reason.
   Never overwrite the other device's session.
6. **Pull cursor.** Add one cursor for each new table in `syncMeta`.
7. The `profiles` mapping carries the 2 new columns.

## Acceptance criteria

- [ ] An offline session with 3 sets drains in the order session, set, set, set.
- [ ] A set whose session push failed stays in the outbox, and is not a dead letter.
- [ ] A retried push of the same set creates one row, not two.
- [ ] No push sends a row with `user_id` null. A test asserts it for every table.
- [ ] A pull brings the global seed rows into Dexie with `user_id` null.
- [ ] A second active session from another device moves to `deadLetters` with a
      reason, and the server row is not changed.
- [ ] A pull of a newer server set overwrites an older local set.
- [ ] `rest_sound_muted` and `rest_seconds_by_exercise` round trip through push and
      pull.
- [ ] `lib/sync/**` coverage is 95 lines, 90 branches and 95 functions or better.
