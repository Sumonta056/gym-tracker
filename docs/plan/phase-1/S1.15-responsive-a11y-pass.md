# Step 1.15 — The responsive pass and the accessibility pass

**Branch:** `feat/phase-1-daily-tracker` · **Size:** M · **Depends on:** 1.13, 1.14
**Unlocks:** 1.16 · **Agent to use:** `ui-reviewer` on every screen

## Context to read first

1. `.claude/rules/accessibility.md` — all four rules.
2. `CLAUDE.md`, the responsive contract table.
3. `tests/e2e/responsive.spec.ts` as it exists.

## State before the step

Every Phase 1 screen is built. No screen has been checked at every width yet.

## Goal

No screen breaks at any width from 320 px to 2560 px, and axe reports nothing
serious.

## Do

1. Walk every screen at 320, 390, 430, 768, 1024, 1440 and 2560 px. The screens are
   `/sign-in`, `/`, `/log`, `/analytics`, `/profile` and `/styleguide`.
2. Fix any horizontal scroll, any clipped text and any target under 44 px.
3. Run the `ui-reviewer` agent against every screen. Fix every drift it reports.
4. Run axe in the end-to-end suite on every route.

## Acceptance criteria

- [ ] No horizontal scroll on any screen, at any of the seven widths.
- [ ] No clipped or truncated text that hides a value the user must read.
- [ ] Every tap target is 44 px or taller, at every width.
- [ ] Exactly one navigation is visible at every width.
- [ ] axe reports zero serious and zero critical issues on every route, on the mobile
      project and on the desktop project.
- [ ] Focus is visible on every interactive element.
- [ ] Body text meets 4.5:1 contrast against the token behind it.
- [ ] `/styleguide` still matches `docs/design/prototype/index.html`.
- [ ] The `ui-reviewer` agent reports no drift on any screen.

## Tests

Extend `tests/e2e/responsive.spec.ts` to cover every Phase 1 route. Add an axe check
per route.

## Verification

1. `pnpm design:check`.
2. `pnpm e2e` on all three Playwright projects.
3. `pnpm verify`.

## Files touched

- `tests/e2e/responsive.spec.ts`
- `tests/e2e/a11y.spec.ts`
- Any screen or component the pass finds broken

## Risk

Never add an exception to `scripts/design-check.mjs` to get past the gate. Fix the
screen instead.

## When the step is done

1. `pnpm verify`
2. The `commit-report` skill.
3. Commit `fix(ui): close the responsive and accessibility gaps`
4. Set **Next step** in `PROGRESS.md` to `1.16`.
