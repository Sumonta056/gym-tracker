## `parseInput` accepts

| Input     | Seconds                            |
| --------- | ---------------------------------- |
| `1:12:05` | 4325                               |
| `72:05`   | 4325                               |
| `72m`     | 4320                               |
| `1h 12m`  | 4320                               |
| `1h12m`   | 4320                               |
| `90`      | 5400 (a bare number means minutes) |
| `1.5h`    | 5400                               |

## `parseInput` rejects

Empty text, `abc`, `1:70:00`, `-5`, `25h`. Each rejection returns a reason the form
can show to the user.

## `parseSheetValue` rules

| Shape                                          | Reading         | Certain |
| ---------------------------------------------- | --------------- | ------- |
| Three dot parts, `1.15.37`                     | `h.mm.ss`       | yes     |
| Colon form, `1:03:13`                          | `h:mm:ss`       | yes     |
| Two dot parts, second part 60 or more, `19.93` | decimal minutes | yes     |
| Two dot parts, second part under 60, `15.54`   | `mm.ss`         | **no**  |
| One number, `25`                               | whole minutes   | yes     |
| `0`, `-`, empty                                | null            | —       |
