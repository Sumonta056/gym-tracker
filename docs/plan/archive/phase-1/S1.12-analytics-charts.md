# Step 1.12 — `/analytics`, the Phase 1 charts

**Branch:** `feat/phase-1-daily-tracker` · **Size:** L · **Depends on:** 1.10, 1.11
**Unlocks:** 1.14 · **Skill to load:** `design-system`

This step is the largest in Phase 1. It holds seven charts. If the session runs long,
stop after the tab bar and the first three charts. Record the stop point in
`PROGRESS.md` as `1.12 part 2`.

## Context to read first

1. `.claude/skills/design-system/` — load it first.
2. `lib/design/tokens.ts` — every chart colour comes from here. Never a raw hex.
3. `components/ui/SegmentedTabs.tsx`. It exists.
4. `lib/metrics/` from step 1.10.
5. `.claude/rules/accessibility.md`, rule 3. A chart needs a text alternative.

## State before the step

The dashboard works. `recharts` is not installed. There is no `/analytics` route.

## Goal

The user reads every Phase 1 trend on a phone and on a laptop.

## Do

1. Install `recharts`.
2. Build the Day, Week and Month tabs with `SegmentedTabs`.
3. Build seven charts. All use Recharts. All read colours from
   `lib/design/tokens.ts`:
   - Weight per day, with the 7-day average line.
   - Calories per day, bars.
   - Steps per day, bars.
   - Average and highest heart rate, two lines.
   - The heart rate zone split for the selected day.
   - A calendar heat map for the streak.
   - The week totals row.
4. Every chart uses `ResponsiveContainer`. Never a fixed pixel width.
5. Every chart has an empty state, and a `role="img"` with an `aria-label` that
   states the trend in words.
6. At 1024 px and up, show two charts per row.

## Acceptance criteria

- [ ] Each of the seven charts renders with an empty series and shows its empty
      state. None of them throws.
- [ ] Switching the tab changes the range passed to `listRange`.
- [ ] No chart sets a fixed pixel width.
- [ ] Every chart colour comes from `lib/design/tokens.ts`.
- [ ] Every chart carries `role="img"` and an `aria-label` that names the trend.
- [ ] The weight chart shows the 7-day average from `lib/metrics/movingAverage`.
- [ ] The heat map shows the streak from `lib/metrics/streak`.
- [ ] One chart per row at 390 px. Two charts per row at 1440 px.
- [ ] No horizontal scroll at 320 px.
- [ ] Every chart follows `.claude/skills/design-system/references/charts.md`: day
      labels, value labels, a goal or average line, end labels on lines, ghost slots,
      the "not enough data" state under 2 points, and a legend for drawn series only.
      Added in this step, after the owner tested one logged day.
- [ ] No two chart labels overlap and none is cut off at 320 px and 390 px.

## Tests

- Component: switching the tab changes the range passed to `listRange`.
- E2E desktop: two charts per row at 1440 px.
- E2E mobile: one chart per row at 390 px.
