## State before the step

The repository writes rows and outbox entries. Nothing drains the outbox. Nothing
talks to Supabase from the app.

## Goal

The outbox drains to Supabase without a lost write and without a duplicate row. The
user can see the sync state.

## Do

1. Write `lib/sync/outbox.ts`: append, list pending in order, mark done, mark failed
   with an attempt count.
2. Write `lib/sync/worker.ts`:
   - **Push.** Drain the outbox in order. Upsert each row on `id`. On success mark it
     done. On failure raise the attempt count and back off: 1 s, 2 s, 4 s, 8 s, 30 s,
     then 60 s as the ceiling.
   - **Pull.** Select rows where `updated_at > cursor`. Write them to Dexie. Then
     move the cursor. Store the cursor in `syncMeta`.
   - **Conflict.** The higher `updated_at` wins. On a tie the server wins.
   - **Triggers.** App start, the window `online` event, and every 30 s while online.
   - **Lock.** Two drains started at once must not double-push.
3. Write `lib/sync/useSyncStatus.ts`. It reports `offline`, `syncing`, `synced` or
   `error`, plus the number of pending writes.

## Acceptance criteria

- [ ] A write with the network down stays in the outbox, and the row is still
      readable through the repository.
- [ ] One drain pushes every pending entry, in outbox order, and clears the outbox.
- [ ] A failed push keeps the entry and raises its attempt count by exactly one.
- [ ] The back-off follows 1, 2, 4, 8, 30, 60, 60, 60 seconds.
- [ ] Pushing the same UUID twice results in one row, not two.
- [ ] A pull with a newer server row overwrites the local row.
- [ ] A pull with an older server row does not overwrite a newer local row.
- [ ] On an equal `updated_at`, the server row wins.
- [ ] The cursor only moves forward. A failed pull does not move it.
- [ ] Two drains started at once do not double-push. The lock holds.
- [ ] `useSyncStatus` reports `offline` when the browser is offline.
- [ ] The worker is the only file in the repository that imports `@supabase/*`
      outside `lib/supabase/`.
