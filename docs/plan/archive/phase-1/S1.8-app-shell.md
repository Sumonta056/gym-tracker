## State before the step

`AppShell` exists from Phase 0. It takes `items`, `action`, `title`, `aside` and
`children`. All eleven primitives exist and appear in `/styleguide`. This step wires
the shell to the five real destinations. **Do not build the primitives again.**

## Goal

Every signed-in route sits inside one shell. The shell shows a bottom tab bar on a
phone and a sidebar on a laptop.

## Do

1. Read `components/ui/AppShell.tsx`. Confirm it already meets the contract below.
   Change only what is missing.
   - Under 1024 px: one content column with 20 px gutters, plus a bottom tab bar
     with five slots and the accent centre action.
   - 1024 px and up: a 240 px left sidebar with the same five destinations as rows,
     content capped at 1100 px and centred, no bottom bar.
   - The tab bar adds `env(safe-area-inset-bottom)`.
2. Define the five destinations in one place: `/`, `/analytics`, `/log` (the centre
   action), `/workouts` and `/profile`. `/workouts` is a Phase 2 route. Point it at a
   placeholder for now.
3. Apply the shell in `app/(app)/layout.tsx`, so every signed-in route uses it.
4. Mark the active destination with `aria-current="page"`.
5. Confirm the `/styleguide` entry still matches the prototype.

## Acceptance criteria

- [ ] The tab bar renders under 1024 px. The sidebar renders at 1024 px and up.
- [ ] Both navigations are never visible at the same width.
- [ ] The active destination carries `aria-current="page"`.
- [ ] Every destination is an `<a>` or a `next/link`, never a `div` with `onClick`.
- [ ] Every tap target is 44 px or taller at 320 px, 390 px, 768 px and 1440 px.
- [ ] The tab bar adds `env(safe-area-inset-bottom)`.
- [ ] Only `AppShell` writes `min-h-dvh` or `max-w-[1100px]`. The design check proves
      this.

## Tests

- Component: drive a mocked match media. Assert the tab bar under 1024 px and the
  sidebar at 1024 px and up.
- Component: the active destination has `aria-current="page"`.
- E2E on all three Playwright projects: no horizontal scroll, and exactly one
  navigation is visible.
