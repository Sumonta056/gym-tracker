2. `.claude/rules/architecture.md`, rule 3, the soft delete rule.

## State before the step

There is no `supabase/` folder. There is no `.env.local`. Supabase is not installed.

## Goal

A Supabase project exists. Migration 0001 creates `profiles` and `daily_entries` with
Row Level Security, the indexes the sync worker needs, and the two triggers.

## Do

1. Ask the user to create the Supabase project. Get the project URL, the anon key and
   the project id.
2. Write `.env.local` with `NEXT_PUBLIC_SUPABASE_URL` and
   `NEXT_PUBLIC_SUPABASE_ANON_KEY`. Confirm `.env.local` is in `.gitignore`.
3. Add the Supabase CLI as a dev dependency.
4. Write `supabase/migrations/0001_phase1.sql`:
   - `profiles` as the specification states.
   - `daily_entries` with these columns: `id uuid pk`, `user_id uuid`,
     `entry_date date`, `walk_seconds integer`, `gym_seconds integer`,
     `avg_heart_rate integer`, `max_heart_rate integer`, `weight_kg numeric(5,2)`,
     `calories_burnt integer`, `steps integer`, `note text`, `created_at timestamptz`,
     `updated_at timestamptz`, `deleted_at timestamptz`.
   - A unique index on `(user_id, entry_date)` where `deleted_at is null`.
   - An index on `(user_id, updated_at)`. The sync pull reads it.
   - Row Level Security on both tables. Four policies each: select, insert, update
     and delete, all `user_id = auth.uid()`.
   - A trigger that sets `updated_at = now()` on every update.
   - A trigger on `auth.users` insert that creates the matching `profiles` row.
5. Apply the migration to the project.

## Acceptance criteria

- [ ] The migration applies cleanly on a fresh database.
- [ ] `daily_entries` holds every column in the list above, with the stated types.
- [ ] Both tables report `rowsecurity = true`.
- [ ] A second insert with the same `(user_id, entry_date)` fails while the first row
      has `deleted_at is null`.
- [ ] A soft-deleted row does not block a new row for the same date.
- [ ] An update changes `updated_at` without the client sending it.
- [ ] A new `auth.users` row creates one `profiles` row.
