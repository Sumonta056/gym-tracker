## State before the step

The sync worker reports its state. There is no `/profile` route.

## Goal

The user controls their targets and their units, sees the sync state, and signs out
cleanly.

## Do

1. Build from the mockup: the header card, the targets list, the data card and the
   sign-out button.
2. Hide the Phase 2 import card behind a flag until Phase 2 lands.
3. The unit toggle changes the display only. Storage stays metric.
4. The sync card shows the pending count and a "Sync now" button.
5. Sign out clears the Dexie database, so a second account never sees old rows.

## Acceptance criteria

- [ ] The unit toggle changes the shown weight but not the stored value.
- [ ] The stored value stays metric after a toggle and a reload.
- [ ] Sign out empties every Dexie table: `dailyEntries`, `profiles`, `outbox` and
      `syncMeta`.
- [ ] Sign out then redirects to `/sign-in`.
- [ ] The sync card shows the pending count from `useSyncStatus`.
- [ ] "Sync now" triggers one drain. Two fast presses do not double-push.
- [ ] The Phase 2 import card is not in the document while the flag is off.
- [ ] Every control has a label. The toggle states its current unit in text, not by
      colour alone.

## Tests

- Component: the import card is absent while the flag is off.
