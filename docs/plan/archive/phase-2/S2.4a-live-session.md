# Step 2.4a — `/workout`: the timer, the set rows and the PR badge

**Branch:** `feat/phase-2-workout-log` · **Size:** M · **Depends on:** 2.2b, 2.3a, 2.7a
**Unlocks:** 2.4b, 2.5, 2.6, 2.8a · **Skills to load:** `design-system`, `add-screen`

The core of Phase 2. The usual case, one more set of the same lift, is one tap.

## Context to read first

1. `.claude/skills/design-system/` and `.claude/skills/add-screen/` — load both.
2. Prototype plate `p3`, Live workout.
3. `lib/db/repository.ts` — the session and set functions from step 2.2b.
4. `lib/metrics/volumeLoad.ts` and `personalRecords.ts` from step 2.7a.
5. `lib/nav.ts` — `isCurrentPath`.

## State before the step

The picker exists. There is no `/workout` route. `/workouts` is a placeholder.

## Goal

The user starts a session, adds sets to exercises, and finishes, on a phone with no
network.

## Do

1. Add `app/(app)/workout/page.tsx` with the `add-screen` skill.
2. `/workouts` gains a "Start a session" button. With an active session it shows
   "Resume" in its place. Keep the rest of the placeholder. Phase 3 rebuilds it.
3. Build from plate `p3`: the running timer, the Finish button, the set and volume
   readout, the active exercise card with its set rows, and the collapsed cards for
   the other exercises.
4. The timer shows now minus `started_at`. It holds no counter in memory.
5. "Add exercise" opens the picker. "Add set" copies the reps and load from the last
   set of the same exercise, or from `lastSetFor` for the first set.
6. The running volume comes from `volumeLoad`. It updates on every set.
7. A set that `isNewRecord` marks shows the `PR` badge at once, with the text "PR",
   not color only.
8. The Workouts tab shows as current on `/workout`.

## Acceptance criteria

- [ ] "Add set" copies the previous reps and load.
- [ ] The volume total changes when a set is added.
- [ ] A heavier set shows the `PR` badge. An equal set does not.
- [ ] The timer survives a remount and reads from `started_at`.
- [ ] Finish sets the session to finished and returns to `/workouts`.
- [ ] The Workouts tab has `aria-current="page"` on `/workout`.
- [ ] Every control is 44 px or taller. axe reports zero serious issues.

## Tests

- Component: one test for each of the first 3 criteria.
- Integration: the timer after a remount, with the fake timers and a fixed
  `started_at`.
- E2E mobile offline: start a session, add 3 sets, finish, reload. Every set is there.
