## State before the step

A session records sets. A set cannot be changed or removed. A closed tab loses the
way back to the session.

## Goal

The user fixes a wrong set, gets a removed set back, and never loses a running
session.

## Do

1. Tap a set row to edit it in a `SheetModal`: reps, load, and a Delete button.
2. Swipe left or long press on a set row also deletes it. Both are extras. The Delete
   button is the real path.
3. A delete shows an undo toast for 5 seconds. Undo calls `restoreSet`. The toast has
   `role="status"`.
4. When the app opens with an active session, show a prompt: Resume or Discard.
   Discard asks once more, then calls `discardSession`.
5. At 1024 px and up, show the exercise list on the left and the active exercise on
   the right.

## Acceptance criteria

- [ ] Editing a set changes the volume total.
- [ ] A deleted set comes back on Undo, with the same id.
- [ ] Delete works with the keyboard alone.
- [ ] A reload with an active session offers Resume and Discard.
- [ ] Discard soft deletes the session and its sets.
- [ ] At 1440 px the list and the active exercise sit side by side. At 390 px they
      stack.
- [ ] No horizontal scroll from 320 px to 2560 px.

## Tests

- Component: edit changes the volume. Undo restores the set.
