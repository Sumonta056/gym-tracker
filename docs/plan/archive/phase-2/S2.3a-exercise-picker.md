## State before the step

The repository lists and creates exercises. No component shows them.

## Goal

The user finds and picks an exercise in 2 taps, or creates one, with no network.

## Do

1. Write `components/workout/ExercisePicker.tsx`. It uses `SheetModal`.
2. Build from plate `p4`: the grab handle, the title, the close button, the search
   field, the muscle group chips, the Recent list, the full list, and the "Create a
   new exercise" button.
3. Recent shows the last used load and reps, plus how long ago. It reads
   `lastSetFor` from the repository.
4. Search calls `listExercises({ query })`. The match ignores case and accents.
5. "Create a new exercise" asks for a name and a muscle group only. It calls
   `createExercise` and then picks the new exercise.
6. The chips are a toggle group with `aria-pressed`, as `SegmentedTabs` is.

## Acceptance criteria

- [ ] The search narrows the list. An empty result shows the create option.
- [ ] A chip filters by muscle group. The All chip clears the filter.
- [ ] Picking an exercise calls the handler once and closes the sheet.
- [ ] The sheet traps focus and closes on Escape.
- [ ] A new exercise with an empty name shows an error tied by `aria-describedby`.
- [ ] Every row and chip is 44 px or taller.
- [ ] The sheet matches plate `p4` at 390 px and at 1440 px.
