## State before the step

`lib/metrics/` holds the Phase 1 functions only.

## Goal

Three pure functions give every lifting number the app shows. None of them throws.

## Do

| File                 | Function                                                    |
| -------------------- | ----------------------------------------------------------- |
| `volumeLoad.ts`      | The sum of reps times weight, per session and per exercise  |
| `epley.ts`           | `weight * (1 + reps / 30)`, the estimated one-rep maximum   |
| `personalRecords.ts` | The best load and the best volume per exercise, with a date |

`personalRecords` also exposes `isNewRecord(set, history)`. The PR badge in 2.4a
calls it.

## Acceptance criteria

**`volumeLoad`**

- [ ] An empty session returns 0.
- [ ] A body-weight set with a null load counts as 0, not a crash.
- [ ] A soft-deleted set is skipped.

**`epley`**

- [ ] One rep returns the load itself.
- [ ] Ten reps at 40 kg returns 53.33.
- [ ] Zero reps returns null. A null load returns null.

**`personalRecords`**

- [ ] A tie breaks on the earlier date.
- [ ] A soft-deleted set is skipped.
- [ ] `isNewRecord` is true for a heavier load, and false for an equal load.
- [ ] The first set of an exercise ever is a record.

**All three**

- [ ] Coverage on `lib/metrics/**` stays 100 percent for lines and functions, and 95
      percent or better for branches.
