# Step 2.2a — The zod schemas and the exercise repository

**Branch:** `feat/phase-2-workout-log` · **Size:** M · **Depends on:** 2.1a
**Unlocks:** 2.2b, 2.3a, 2.7a, 2.7b, 2.9a

One schema per entity. The form, the outbox and the importer all import it. This
step writes the 3 shapes before any code uses them.

## Context to read first

1. `.claude/rules/architecture.md`, "Shapes" and rules 1 to 3.
2. `lib/schema/dailyEntry.ts` and `lib/schema/profile.ts` — the style to follow.
3. `lib/db/repository.ts` — the write, outbox and `SignedOutOnThisDevice` pattern.

## State before the step

Dexie has the 3 new tables. No schema and no repository function uses them.

## Goal

The 3 shapes exist once, and a screen can list, create, rename, archive and restore
an exercise with no network.

## Do

1. Write `lib/schema/exercise.ts`, `lib/schema/workoutSession.ts` and
   `lib/schema/workoutSet.ts`. Export the input type and the draft type of each.
   - `muscle_group` is an enum of the 7 groups.
   - `reps` is a whole number, 1 or more. `weight_kg` is null or 0 to 500, two
     decimals. `rpe` is null or 1 to 10.
2. Add `rest_sound_muted` and `rest_seconds_by_exercise` to `lib/schema/profile.ts`.
3. Extend the repository:
   ```ts
   listExercises(filter?: { muscleGroup?: MuscleGroup; query?: string }): Promise<Exercise[]>
   createExercise(input: ExerciseInput): Promise<Exercise>
   renameExercise(id: string, name: string): Promise<Exercise>
   archiveExercise(id: string): Promise<void>
   restoreExercise(id: string): Promise<void>
   ```
4. `listExercises` returns the global rows and the user's own rows. It hides archived
   and soft-deleted rows. The query match ignores case and accents.
5. A global row is read only. `renameExercise` and `archiveExercise` on a global row
   throw a named error.
6. Every write shares one transaction with its outbox entry, and checks `signed_out`.

## Acceptance criteria

- [ ] Each schema accepts a valid row and rejects each bad field with a message.
- [ ] `listExercises({ query: 'bench' })` finds `Bench Press`. `'BÉNCH'` finds it
      too.
- [ ] `createExercise` writes the row and one outbox entry in one transaction.
- [ ] `archiveExercise` hides the row from `listExercises`. `restoreExercise` shows it
      again.
- [ ] A write to a global row throws and writes no outbox entry.
- [ ] A write on a signed-out device throws `SignedOutOnThisDevice`.
