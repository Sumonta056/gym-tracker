# Step 2.9a — The CSV parser, tests first

**Branch:** `feat/phase-2-workout-log` · **Size:** M · **Depends on:** 2.2a
**Unlocks:** 2.9b, 2.10 · **Agent to use:** `test-writer`

The parser reads the old sheet and says which cells it is not sure of. It never
guesses and it never writes.

## Context to read first

1. `lib/duration.ts` — `parseSheetValue` returns `certain: false` for a value such as
   `15.54`.
2. `lib/schema/dailyEntry.ts` — the target shape.
3. `docs/plan/phase-1/S1.4-duration.md` — the rules that decide a `review` cell.
4. `tests/fixtures/gym-sheet.csv` — the real 16-row sheet. The owner supplies it.

## State before the step

There is no `lib/csv/` folder. The old sheet lives outside the app.

## Goal

A pure function turns the sheet into rows, each cell marked `ok`, `review` or `error`
with a reason.

## Do

1. Write `lib/csv/import.ts`:
   ```ts
   parseSheet(text: string, options: { year: number }): ParsedSheet
   ```
2. Read the header row. Map the 8 sheet columns to the daily entry fields.
3. Use `parseSheetValue` for both time columns. `certain: false` gives a `review`
   cell with both readings.
4. Parse `August 12` style dates with the given year.
5. Validate each row with `dailyEntrySchema`. A schema failure gives an `error` cell
   with the schema message.
6. Report a missing column, an extra column and a blank row. Never throw.
7. Handle quoted fields and a comma inside quotes. Add no CSV dependency.

## Acceptance criteria

- [ ] The real 16-row sheet parses to 16 rows.
- [ ] The set of `review` cells is exactly the set the rules of step 1.4 predict.
- [ ] A missing column, an extra column and a blank row are reported, not thrown.
- [ ] A `review` duration carries both readings, for example `15m 54s` and
      `15.93 min` for `15.54`.
- [ ] The parser writes nothing. A test asserts the repository is never called.
- [ ] `lib/csv/**` coverage is 95 percent or higher.

## Tests

One `it` for each criterion. Write the expected `review` set by hand from the sheet
before the code.

## Verification

1. `pnpm test:cov`. Read the `lib/csv` rows.
2. `pnpm verify`.

## Files touched

- `lib/csv/import.ts` and its test
- `tests/fixtures/gym-sheet.csv`
- `vitest.config.ts`, for the `lib/csv/**` floor

## Risk

The sheet holds personal health data. Before it is committed, ask the owner if the
fixture may live in the repository. If not, commit a copy with changed numbers but
the same cell shapes.
