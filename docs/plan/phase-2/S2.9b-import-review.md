## State before the step

The parser marks every unclear cell. No screen shows them.

## Goal

The user sees every row, resolves every unclear cell, and knows the true count left.

## Do

1. The Data card on `/profile` gains "Import the old sheet". It opens a file input
   with a label, and a year field. The year is asked once, up front.
2. Show every parsed row. Under 640 px each row is a card. At 1024 px and up it is a
   table. No horizontal page scroll at any width.
3. Mark each `review` cell with `--color-warn` and the text "Check".
4. For a `review` duration, show both readings side by side and let the user pick one.
5. Show the true count of cells that still need a pick. Never a guessed number.
6. "Apply to all similar" sets the same reading for every cell with the same column
   and the same raw shape, for example `mm.ss` in the gym column.
7. An `error` row shows its reason and is left out of the import.
8. The Apply button stays disabled until the count is 0.

## Acceptance criteria

- [ ] The count matches the number of `review` cells in the parsed sheet.
- [ ] Picking a reading lowers the count by one.
- [ ] "Apply to all similar" changes every matching cell and only those.
- [ ] Apply is disabled while the count is above 0.
- [ ] Every pick is a real `button` or radio input with a label.
- [ ] No horizontal scroll at 320 px.
