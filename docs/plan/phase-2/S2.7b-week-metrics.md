## State before the step

The lifting metrics exist. Nothing computes a weekly share or a gap.

## Goal

Three more pure functions for the Phase 2 week charts. None of them throws.

## Do

| File                   | Function                                      |
| ---------------------- | --------------------------------------------- |
| `muscleBalance.ts`     | The share of weekly volume by muscle group    |
| `sessionGaps.ts`       | The day gaps between sessions, as a histogram |
| `caloriesPerMinute.ts` | Calories divided by gym minutes, one per day  |

`muscleBalance` also returns the groups below a threshold. The default is 15
percent. The warning in 2.8b reads it.

## Acceptance criteria

**`muscleBalance`**

- [ ] The shares add up to 100.
- [ ] An empty week returns an empty result.
- [ ] A group at 14 percent is below the threshold. A group at 15 percent is not.

**`sessionGaps`**

- [ ] The real dates, 2 September to 13 September, give the gaps 1, 3, 3, 3, 1.
- [ ] One session returns no gap.
- [ ] Two sessions on one date count as one day.

**`caloriesPerMinute`**

- [ ] Zero gym minutes returns null, never infinity.
- [ ] A null calorie value returns null.

**All three**

- [ ] Coverage on `lib/metrics/**` stays 100 percent for lines and functions, and 95
      percent or better for branches.

## Verification

1. `pnpm test:cov`. Read the `lib/metrics` rows.
2. `pnpm verify`.

## Files touched

## Risk

The shares can add up to 99 or 101 after rounding. Round with the largest remainder
method, and test that the sum is exactly 100.
