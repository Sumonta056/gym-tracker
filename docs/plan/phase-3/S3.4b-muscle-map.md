# Step 3.4b — The muscle map

**Branch:** `feat/phase-3-coach-plans` · **Size:** S · **Depends on:** 3.2
**Unlocks:** 3.7 · **Skills to load:** `design-system` · **Agent to use:** `ui-reviewer`

## Context to read first

1. `docs/specs/2026-09-24-coach-plans-design.md`, section 12.
2. `docs/data/body-polygons.json`, `docs/data/body-polygons.LICENSE` and the region
   table in `docs/data/README.md`.
3. `lib/design/tokens.ts` and `components/charts/MuscleBalanceChart.tsx` — the colour
   per muscle group. The map uses the same ones.
4. The accepted mockup, the Muscles view on the guided step plate.

## State before the step

`lib/plans/coach.ts` carries `muscles.primary` and `muscles.secondary` on every step.
Nothing draws them.

## Goal

Any step, any plan and any session can show which muscles it works, on a body, with
the words beside it.

## Do

1. `lib/design/body.ts`:
   - `BODY_VIEWBOX = '0 0 100 200'`.
   - `BODY_FRONT` and `BODY_BACK`: `Record<BodyRegion, string[]>`, copied from
     `docs/data/body-polygons.json` by `scripts/coach-data.mjs`, never by hand.
   - The MIT notice as a comment block at the top. This is the one allowed comment,
     because the licence requires it.
   - `MUSCLE_REGIONS`: the table from `docs/data/README.md`, Free Exercise DB muscle
     to app group and body regions.
2. `components/plans/MuscleMap.tsx`:
   - Props: `primary: Muscle[]`, `secondary: Muscle[]`, `size: 'chip' | 'card' | 'frame'`.
   - 2 inline `<svg>` elements, front and back, with the polygons. A primary region
     fills with the group colour token. A secondary region fills the same at 55
     percent. Every other region fills `--color-surface-2` with a `--color-border`
     stroke.
   - `frame`: fills a 3 : 2 box, the figures 88 px wide on a 390 px phone, with Front
     and Back under them and the main or helper key in the corner.
   - `card`: 52 px wide, for the laptop image row. `chip`: 26 px wide, for a plan
     card.
   - `role="img"` and an `aria-label` that reads `Works chest. Also shoulders and
triceps.`
   - Colours come from `lib/design/tokens.ts`. No raw hex.
3. `components/plans/MuscleTags.tsx`: 1 chip per muscle, the primary solid, the
   secondary at 55 percent, with a dot in the group colour and the name. The dot is
   `aria-hidden`; the text carries the meaning.
4. Add both to `/styleguide`, with a selector over the 26 steps, so Checkpoint A can
   check every map by eye.

## Acceptance criteria

- [ ] `BODY_FRONT` and `BODY_BACK` equal the JSON file. A test reads both.
- [ ] Every `muscles` entry in `lib/plans/coach.ts` has a row in `MUSCLE_REGIONS`.
- [ ] A primary region renders with the group colour. A secondary at 55 percent.
- [ ] `MuscleMap` for Flat Dumbbell Press lights chest in front, front and back
      deltoids, and triceps on both views.
- [ ] The `aria-label` names every muscle. `MuscleTags` repeats them as text.
- [ ] `pnpm design:check` passes: no raw hex, no own frame.
- [ ] The `frame` size has no horizontal scroll at 320 px.
