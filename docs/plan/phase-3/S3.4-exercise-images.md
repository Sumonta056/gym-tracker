# Step 3.4 — The exercise images, offline

**Branch:** `feat/phase-3-coach-plans` · **Size:** S · **Depends on:** 3.2
**Unlocks:** 3.7

## Context to read first

1. `docs/specs/2026-09-24-coach-plans-design.md`, section 7.
2. `docs/My Gym Plan.html` — the `IMGS` object. 26 names, 2 JPEG images each, as
   base64. Each image is 420 × 280.
3. `app/sw.ts` and `next.config.*` — how Serwist builds the precache list.
4. `lib/plans/coach.ts` from step 3.2. Every step already names its 2 image paths.
5. `sharp` is in the pnpm store through Next, but it is not a direct dependency.

## State before the step

The images exist only inside the HTML file. `public/` holds the icons and nothing else.

## Goal

Every step image is on the phone before the user reaches the gym.

## Do

1. **Stop and ask the owner** to confirm the image licence, and whether the repository
   is public. Do not commit an image before the answer.
2. Add `sharp` as a dev dependency. It runs on the developer machine only. It never
   reaches the browser bundle.
3. Write `scripts/exercise-image.mjs`. It is the one converter, and step 3.11 reuses
   it:
   ```
   node scripts/exercise-image.mjs <source> <slug> <start|end>
   node scripts/exercise-image.mjs --from-html "docs/My Gym Plan.html"
   ```
   - `<source>` is an `https` link, a local file, or a `data:image/...` value.
   - It resizes to cover 420 × 280, centred, and never upscales a smaller image. It
     writes WebP, quality 80, to `public/exercises/<slug>-<side>.webp`.
   - It strips the metadata, so the same source always gives the same bytes.
   - It rejects a source that is not an image, or that is larger than 5 MB.
   - `--from-html` reads the `IMGS` object, maps each name to its slug in
     `lib/plans/coach.ts`, and writes all 52 files.
4. Run `--from-html`. There is no upload screen and no image hosting. The files are
   committed with the code, and Vercel serves them with the app.
5. Precache the 52 files. Use the Serwist `additionalPrecacheEntries` option, or the
   `public/` glob, whichever the Serwist version supports. Give each entry a revision,
   so a changed image replaces the old one.
6. Add a unit test that every `step.images` path is a real file.

## Acceptance criteria

- [ ] `public/exercises/` holds exactly 52 files.
- [ ] Every step in `lib/plans/coach.ts` has a start file and an end file.
- [ ] The 52 files add less than 1.5 MB in total.
- [ ] The build's precache manifest lists all 52.
- [ ] With the network down and a cold cache after the first install, a step image
      loads.
- [ ] The owner's licence answer is in the commit report.

## Tests
