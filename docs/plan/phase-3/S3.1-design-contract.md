## Do

1. Add 5 plates to `docs/design/prototype/index.html`, numbered after the last plate:
   - Choose a plan · `/workouts`
   - Plan preview · `/workouts/[planId]`
   - Guided step · `/workout`, plan mode
   - Session done · `/workout`, after Finish
   - Guided step at 1440 px, in the laptop section
2. Reuse the prototype classes: `.frame`, `.card`, `.hero`, `.setrow`, `.cell`, `.tick`,
   `.btn`, `.chip`, `.tabbar`. Add 3 classes only: `.stepcard`, `.stepbar` and
   `.plancard`.
3. The guided step plate has no `.tabbar`. Its header carries the back control, the
   title and the elapsed time.
4. Use 4 real images from `docs/My Gym Plan.html` in the plates, as base64, the way the
   source file does. The prototype stays one self-contained file.
5. Add Phase 3 to the delivery table in `docs/specs/2026-09-20-gym-tracker-design.md`.
6. Add `docs/plan/03-phase-3.md` and the spec to the table in `CLAUDE.md`, and add
   Phase 3 to its **Phases** paragraph.
7. Add Phase 3 to the **Phases** list in `PROGRESS.md`.
