## Do

1. Run the `test-writer` agent with the acceptance list below. The tests come first.
2. `lib/metrics/planSuggestion.ts`:
   ```ts
   lastDoneByPlan(sessions: WorkoutSession[]): Partial<Record<PlanId, string>>
   suggestPlan(plans: Plan[], sessions: WorkoutSession[]): PlanId | undefined
   ```
   Count only finished sessions with `deleted_at` null. A session with 2 plan ids
   counts for both. The date is `entry_date`.
3. `lib/metrics/planProgress.ts`:
   ```ts
   stepStatuses(steps: PlanStep[], sets: WorkoutSet[], cursor: PlanCursor):
     ('done' | 'skipped' | 'now' | 'todo')[]
   sessionSummary(steps: PlanStep[], sets: WorkoutSet[], cursor: PlanCursor):
     { doneSteps: number; skippedSteps: number; setCount: number; volumeKg: number }
   ```
   A step is `done` when it has 1 or more sets, not soft-deleted. `done` wins over
   `skipped`. The cursor step is `now` unless it is `done`.

## Acceptance criteria

- [ ] `suggestPlan` returns a plan that was never done before any plan that was.
- [ ] `suggestPlan` breaks a tie on the order of `listPlans()`.
- [ ] `suggestPlan` counts a combined session for both of its plans.
- [ ] `suggestPlan` ignores an active session and a soft-deleted session.
- [ ] `suggestPlan([], [])` returns undefined.
- [ ] `stepStatuses` marks a skipped step with a set as `done`.
- [ ] `stepStatuses` ignores a soft-deleted set.
- [ ] `sessionSummary` of an empty session is 0, 0, 0 and 0.
- [ ] `sessionSummary` volume equals `volumeLoad` for the same sets.
- [ ] A body-weight set with a null load adds 0 volume, not an error.

## Tests
