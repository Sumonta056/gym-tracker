## State before the step

`/workout` runs a free Phase 2 session. It ignores `plan_ids`.

## Goal

The user goes through a plan one exercise at a time, sees how to do each one and which
muscles it works, and logs every set, with the least taps.

## Do

1. `/workout` reads the active session. With `plan_ids`, it shows plan mode. With
   null, it shows the Phase 2 free session, unchanged.
2. `PlanStepHeader`:
   - Left, 44 × 44: a back button to the previous step. On step 1, a leave link to
     `/workouts` instead. The session stays active when the user leaves.
   - Centre: the plan title, then `Step 2 of 9 · Chest`.
   - Right: `Elapsed` and the time from `started_at`.
3. `StepProgress`: an `<ol>` with 1 bar per step. The colour comes from
   `stepStatuses`. The current bar moves with a `motion` fill, off under
   `prefers-reduced-motion`. Each `<li>` holds a visually hidden label, for example
   `Step 2, Flat Dumbbell Press: now`.
4. `StepFrame`, the phone image card:
   - 1 box, 3 : 2, the card width, with `next/image` and a fixed aspect ratio, so the
     layout does not jump.
   - Under it a segmented control with 4 `<button>` elements, 40 px tall, with
     `aria-pressed`: `Start`, `End`, `▶ Play`, `Muscles`. Play is the default.
   - Start shows `images.start` with the label `1 · Start`. End shows `images.end`
     with `2 · End` on the accent. Play fades start to end and back, 2.4 s per cycle,
     with the label following. A tap on the frame pauses it. Under
     `prefers-reduced-motion` Play shows End still.
   - Muscles shows `MuscleMap` in `frame` size inside the same box, with Front and
     Back under the figures and the main or helper key in the corner.
   - The alt texts `<name>, start position` and `<name>, end position`.
   - A failed image keeps its box and shows the name on `--color-surface-2`.
   - The name as the page `<h1>`, the how-to text, then `MuscleTags`.
   - The pills `Target 3 × 10–12`, `Last time 14 kg × 10`, and `WatchPill` from 3.7
     when the step has a `video`.
5. The set rows are the Phase 2 rows. On the first visit to a step, create 3 rows from
   `lastSetFor`. A first time leaves the weight empty with the hint `Pick a light
weight`. A body-weight step shows `Body` and stores a null weight.
6. A tick starts the Phase 2 rest timer. The rest card sits under the sets.
7. The foot, in a fixed bar: `Skip` and `Next step`, with the next name under it in
   small text. The last step shows `Finish session`. Skip adds the step to
   `cursor.skipped`, then moves on.
8. Every move writes the cursor through `setPlanCursor` at once. A reload reads it and
   resumes. No cursor: resume at the first step with no sets. The frame view resets to
   Play on every step.
9. `AppShell` gains `mode="focus"`. Under 1024 px it hides the bottom bar. At 1024 px
   and up the sidebar stays. Only `AppShell` writes the frame, so the design check
   still passes.
10. `tests/e2e/responsive.spec.ts`: add a named exception for `/workout` in plan mode
    under 1024 px, with the reason "focus mode, agreed on 2026-09-24, the header
    carries the leave link". Assert the leave link or the back button is visible
    instead.

## Acceptance criteria

- [ ] A free Phase 2 session still shows the Phase 2 screen.
- [ ] Next moves the cursor by 1 and saves it.
- [ ] Back moves the cursor back by 1. Step 1 shows the leave link.
- [ ] Skip records the step in `skipped` and moves on.
- [ ] A skipped step that later gets a set shows as done.
- [ ] The frame opens on Play. Each of the 4 buttons shows its view. The pressed
      button carries `aria-pressed="true"`.
- [ ] Muscles shows the map for the current step, and the tags under the name name
      the same muscles.
- [ ] The rows fill from `lastSetFor`, and are empty on a first time.
- [ ] `+ Add set` copies the row above.
- [ ] A tick starts the rest timer.
- [ ] A reload resumes at the same step, with the same skips.
- [ ] The elapsed time is correct after a reload.
- [ ] Every control is 44 px or taller, except the 4 segment buttons at 40 px inside
      a 48 px track. `Skip` and `Next step` are 54 px.
- [ ] No horizontal scroll at 320 px, even with `Dumbbell Overhead Extension`.
