## What ships to production, and how

| Data                        | Where it lives in the app | How it reaches production                        |
| --------------------------- | ------------------------- | ------------------------------------------------ |
| The 4 plans, 26 steps       | `lib/plans/coach.ts`      | In the JavaScript bundle. The Vercel build.      |
| The muscles per step        | `lib/plans/coach.ts`      | Same.                                            |
| The video links             | `lib/plans/coach.ts`      | Same.                                            |
| The body polygons           | `lib/design/body.ts`      | Same.                                            |
| The 52 WebP images          | `public/exercises/`       | Static files on Vercel. Precached by the worker. |
| The coach exercise rows     | `supabase/migrations/`    | Applied in 3.3 through the Supabase MCP.         |
| `workout_sessions.plan_ids` | `supabase/migrations/`    | Same migration.                                  |

Nothing is uploaded by hand. A merge to `main` and the owner's push is the whole push.

## Do

1. Run the full `pnpm verify`. It must be green.
2. Deploy the branch to a Vercel preview. Check the preview build log lists
   `/exercises/` in the precache manifest.
3. On the iPhone, open the preview app online once, so the new worker installs.
4. Turn on flight mode. Close the app. Open it again.
5. Open `/workouts`. Check the 4 plan thumbnails and the 4 muscle chips.
6. Open each of the 4 previews. Check every thumbnail and the watch pills.
7. Start Chest + Triceps. Step through all 9 steps. On each, check Start, End, Play
   and Muscles.
8. Log 1 set on 3 steps. Skip 1 step. Finish. Read the summary.
9. Turn flight mode off. Open the laptop. Confirm the sets and the session. Tap a
   watch pill online and see the browser open.
10. Tick every item in the Phase 3 checklist. Record each result in the report.
11. Merge to `main`. The owner pushes. Vercel builds production. Repeat steps 3 to 5
    on the production URL.
