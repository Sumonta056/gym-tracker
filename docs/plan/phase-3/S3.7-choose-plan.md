## State before the step

`/workouts` shows the title, Start a session or Resume, and the day-card history. No
plan screen exists.

## Goal

The user sees the 4 plans, sees which one to do today, and starts 1 plan or 2. The free
session and the history still work as before.

## Do

1. `/workouts`, from the plate, top to bottom:
   - The header: the micro label, `Workouts`, and the sync chip.
   - `SuggestedPlanHero`: the plan from `suggestPlan`, the reason `You did it least
recently: 6 days ago`, and a link `See the 9 steps` to the preview.
   - `PlanCard` × 4: a thumbnail of the first step's start image, the title,
     `9 exercises · last done 6 days ago`, a `MuscleMap` in `chip` size with the
     plan's primary and secondary muscles, and a round mark. The card is a `<button>`
     with `aria-pressed`. The mark shows a check when selected.
   - Selection: 1 or 2 plans. A third tap drops the oldest selection. The suggested
     plan starts selected.
   - The missed-day note, in the coach's words.
   - The free session card: `SessionLauncher` as it is, under a `Free session` label.
   - `WorkoutHistory` as it is.
   - The Start bar above the tab bar: `Start Chest + Triceps`, then
     `9 exercises · about 55 min` from `planMinutes`. For 2 plans, `· combined`. With
     no selection, the button is disabled and reads `Pick a plan to start`.
2. `/workouts/[planId]`, from the plate:
   - A back link `Plans`, the title, `9 exercises · 27 sets · about 55 min`.
   - 1 card per group. Each row: the number, a 60 × 40 thumbnail, the name,
     `3 × 10–12 · last 12 kg`, and a watch pill when the step has a `video`. A first
     time reads `3 × 10–12 · first time`.
   - The watch pill is an `<a>` with `target="_blank"` and `rel="noopener"`, 44 px
     tall, labelled `Watch <name>`. Offline it still shows. The browser handles the
     failure.
   - `Start Chest + Triceps` at the foot.
   - `generateStaticParams` returns the 4 ids, so the service worker precaches the 4
     pages. An unknown id returns `notFound()`.
3. Start calls `startPlanSession`, sets the cursor to step 0, then routes to
   `/workout`. An active session shows the Phase 2 resume-or-discard prompt first.
4. At 640 px and up, the plan cards take 2 columns. At 1024 px and up, the hero spans
   the width and the cards take 2 columns.

## Acceptance criteria

- [ ] The hero names the plan that `suggestPlan` returns.
- [ ] A plan never done reads `never done`.
- [ ] A third selection drops the oldest one.
- [ ] With no selection, Start is disabled.
- [ ] Start with 2 plans calls `startPlanSession` once, with both ids in selection
      order.
- [ ] Start with an active session shows the prompt and starts nothing.
- [ ] `Start a session`, `Resume` and the day cards still work, with their tests
      unchanged.
- [ ] `/workouts/nope` returns the 404 page.
- [ ] Every card, button and watch pill is 44 px or taller.
- [ ] The thumbnails carry `alt=""`. The muscle map on a card carries its label.
- [ ] Both routes render with no network after the first visit.
