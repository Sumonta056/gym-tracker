Gym Tracker · fix track · wave 2 · step B2

Test the /workout bottom bar in the iOS Simulator

On the owner's iPhone, in the home-screen app, the bottom bar sat about 58 px above the screen edge right after "Start a session". B2 applied fix F5. This plan proves, before and after, whether F5 removes the gap.

Bug gap ≈ 58 px Top safe area, 393 × 852 phone 59 px Before 3f04ce2 After 5be42a8

Why the Simulator can help

Playwright cannot run the iOS standalone mode, so B1 found no failure in e2e. The Simulator runs real iOS Safari, and "Add to Home Screen" starts the app in standalone mode, with the black-translucent status bar and viewport-fit=cover. Those are the 2 settings that B1 suspects.

The rule of this test: the old code must show the gap first. If the Simulator does not show the bug on the old code, a pass on the new code proves nothing.

Before you start

  • Install Xcode from the Mac App Store, open it 1 time, and accept the license.
  • Point the tools at it: sudo xcode-select -s /Applications/Xcode.app
  • Keep the Mac on AC power with the lid open.
  • No e2e run may use the shared test account during this test.

The flow

  1. Check the install and pick a phone

    Pick an iPhone with a 393 × 852 screen, the same as the owner's phone.

    xcrun simctl list devices available | grep -E "iPhone 1[56]"
orca emulator attach "iPhone 16" --json

    The device boots and shows live in the Orca emulator pane.

  2. Serve the old code as a production build

    The dev server has no service worker and loads pages in a different way, so use pnpm build and pnpm start. Build in a temporary worktree so the main folder stays on fix/feedback-fixes. 

    git worktree add /Users/cefalo_1/Documents/Projects/gym-tracker-sim 3f04ce2
cd /Users/cefalo_1/Documents/Projects/gym-tracker-sim
cp ../gym-tracker/.env.local .
export PATH="$HOME/.nvm/versions/node/v$(cat .nvmrc)/bin:$PATH"
pnpm install --frozen-lockfile && pnpm build && pnpm start

    The Simulator uses the Mac's network, so http://localhost:3000 opens in it. localhost is a secure context, so the PWA rules apply as they do on HTTPS.

  3. Sign in and add the app to the home screen

    xcrun simctl openurl booted http://localhost:3000
orca emulator ax --json          # find the email and password fields
orca emulator tap 0.5 0.42 --json
orca emulator type "<test account email>" --json
    • Sign in with the e2e test account from .env.test.local.
    • Tap Share, then "Add to Home Screen", then Add.
    • Press Home: orca emulator button home --json. Then tap the new Gym Tracker icon. The app now runs in standalone mode.

  4. Run the scenario and take the "before" screenshots

    Tap Workouts, then "Start a session". On the old code, Start does a full document load: window.location.assign('/workout'). 

    xcrun simctl io booted screenshot before-start.png
orca emulator ax --json > before-start-ax.json

    Repeat for each B1 scenario: no session, Start, a set logged, the Resume link, and a reload of a running session.

  5. Swap to the new code and repeat

    Check out 5be42a8 in the same worktree, then build and start again. Delete the home-screen icon and add it again, so the old service worker cache cannot serve the old build. Then take the "after" screenshots. 

    git checkout --detach 5be42a8
pnpm build && pnpm start
xcrun simctl io booted screenshot after-start.png

  6. Measure the gap

    • Pixels: a small script scans each screenshot from the bottom up, finds the lowest row of the tab bar by its surface colour, and divides by the device scale (3 on an iPhone 16). The result is the gap in CSS px.
    • Accessibility tree: the nav frame from orca emulator ax gives y + height as a fraction of the screen. 1.0 means the bar touches the edge.

    The 2 measures must agree within 2 px.

  7. Clean up

    orca emulator kill --json
git -C /Users/cefalo_1/Documents/Projects/gym-tracker worktree remove ../gym-tracker-sim

    Stop the server first. The screenshots go into the report as proof.

Limits

  • The Simulator is not a real phone. It runs on the Mac, and the status bar and safe area can differ from the iPhone. The owner's real iPhone check stays the final proof.
  • The Orca emulator drives private simulator APIs. A new Xcode version can break it.
  • orca emulator type sends US-ASCII only.
  • Coordinates for tap are fractions from 0 to 1, from the top left, never pixels.
